# Folders are routes

The Next.js App Router has one big idea: **your folder structure is your
routing config**. No `routes.tsx`, no manual `<Route>` wiring.

A folder becomes a URL. A `page.tsx` inside it makes the folder routable.
That's it.

```
app/
├── page.tsx          → /
├── about/page.tsx    → /about
└── posts/
    ├── page.tsx      → /posts
    └── [slug]/page.tsx  → /posts/anything
```

Folders wrapped in `[brackets]` are dynamic — they match anything in that
segment and pass the value to the page as a parameter. One file, infinite
URLs.
